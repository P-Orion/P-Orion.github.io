# BrainBench data provenance and release scope

## Published snapshot

[`js/data.js`](../js/data.js) contains the aggregate values rendered by the dashboard. Its source comment identifies `analysis_results.xlsx`, generated **2026-02-22**, as the originating workbook.

The workbook itself is not included here. These values are the published project snapshot, not measurements generated by running this website.

The snapshot covers 1,000 probability/statistics questions, 900 calculus questions, and 644 Grade 8 math questions: **2,544 per model**, or **7,632 model responses** across the three displayed models.

## Available artifacts

- Dashboard source and aggregate values.
- Methodology and dataset descriptions.
- Team attribution and the research presentation poster.

## Artifacts outside this release

- Python evaluation runner and dependency/environment configuration.
- Original XML datasets and individual question/answer records.
- Raw prompts, model responses, verification logs, and results workbook.
- Complete hardware, model digest, inference configuration, and repeated-run metadata.

Those artifacts are needed to independently reproduce or audit the underlying model experiments. This dashboard alone supports inspection of the published aggregate results.

## Interpreting the presentation

The showcase poster and website snapshot can reflect different stages of the research. Use the dashboard's data file for its displayed values; do not combine poster figures and dashboard figures into a single experimental claim.

The research paper is **under peer review**, as reported in Orion's current resume. It is not presented here as an accepted or published paper.
